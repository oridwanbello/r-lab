# Change Log

All notable changes to the R Lab extension will be documented in this file.

## [0.4.1] - Unreleased

### Added

- Console Type Selector: Added `arf` support to the `r-lab.rConsoleType` setting (now `arf/radian`) to explicitly enforce bracketed paste for arf users utilizing shell aliases, preventing multiline execution errors.
- Settings Decoupling: The "Auto Detect" console logic is now 100% standalone and no longer relies on reading the `r.bracketedPaste` setting from the external `vscode-R` extension, preventing corrupted console states caused by leftover user configurations.

### Fixed

- Help Panel: The "Run" button in help documentation now automatically extracts and auto-loads the required package via `library()` before execution.
- Help Panel: The "Run" button now perfectly mimics the terminal bracketed-paste configurations (including `arf/radian` settings) to safely wrap multi-line statements in ANSI escape sequences, preventing syntax errors in Python-based consoles.

## [0.4.0] - 2026-06-11

### Added

- Rebranded the extension from **R Layout** to **R Lab**.
- Restored terminal detection on startup to prevent duplicate R Console instances.
- Sequential terminal loading logic to guarantee the `R Console -> Terminal -> Tools` tab order on slow Windows ConPTY engines.
- Plot Export Size Estimate: Added real-time estimated file sizes for plot exports in the preview window.
- Visuals Viewer: Added a Viewer subtab inside the combined Visuals tab for R `viewer()` outputs (Shiny, htmlwidgets, package vignettes) with history navigation, delete/clear actions, dark mode, and workspace integration.
- Plot Zoom & Pan: Added interactive zoom (scroll, pinch, buttons) and drag-to-pan support in the Visuals tab's Plots subtab.
- Plot Export: Added export settings for PDF, SVG, EPS, PNG, and JPG with configurable width, height, and units.
- Settings Expansion: Added `r-lab.restoreCustomPanelPositions` to preserve moved panels, `r-lab.protectLayoutTabs` to restore accidentally closed R Lab webviews and the owned shell Terminal, and `r-lab.plotOutputDir` for explicit plot directories.
- Console Type Selector: Added `r-lab.rConsoleType` setting (Auto Detect, Standard R, Radian) to explicitly enforce bracketed paste for Radian users utilizing shell aliases, preventing multiline execution errors.
- QA Runbook: Added an extensive manual testing guide (`docs/QA.md`) to establish standard pre-release testing procedures.

### Changed

- Refactored all configuration settings to the `r-lab.*` namespace.
- Normalized path verification in the local viewer proxy server case-insensitively on Windows to resolve the blank viewer pages.
- Unobtrusive Notifications: Moved plot export and copy-to-clipboard success messages to the VS Code status bar instead of persistent popups.
- UI Refinements: Refined responsive gap and padding alignment in the Plot Export sidebar.
- Widget Placeholder: Adjusted the interactive widget placeholder text size and alignment for better visual balance.
- Workspace Previews: Updated complex object previews (lists, data frames, tibbles) to `{}` formatting with inline R types, adjusted truncation, and horizontal scrolling.

### Fixed

- vscode-R Compatibility: Fixed a bug where `vscode-R` would throw "No text editor active" warnings when plots were generated by preventing the Visuals tab from stealing the active editor group context when it reveals asynchronously.
- Webview Focus Stealing: Resolved persistent "No text editor active" warnings during execution by forcefully restoring text editor focus immediately after users interact with buttons inside any of the webview panels.
- Multi-Pane Plots: Fixed an issue where complex Base R plots using `layout()` (like `filled.contour`) were improperly split and saved as multiple partial plots by implementing a strict `par("page")` check in the plot device hook.
- Windows Blank Plot: Fixed a bug where the very first plot generated on Windows would often render as a blank white screen by switching the internal background device router to `pdf(file=NULL)`.
- Race Conditions: Resolved latent race conditions in the file watchers:
    - Added deterministic file sorting and double duplicate-guards to the Visuals tab's Plots subtab to prevent out-of-order histories and duplicate entries on fast filesystems.
    - Implemented an atomic `.workspace_meta.txt` completion signal to prevent the Workspace Panel from attempting to read partially-flushed R data files.
- Interactive Widgets & Plots Sync: Fixed skipped plot indexing. Widgets now use a single placeholder in the Plot Gallery and are deleted only from the Viewer tab.
- Layout Robustness: Fixed "No text editor active" errors during panel moves, and ensured popped-out panels return exactly to their original grid slots.
- Viewer History: Fixed a UI state bug causing the Viewer tab to display blank frames when scrolling through history.
- Viewer Toolbar: Added 'Delete Current' and 'Clear All' buttons.
- Windows File Watcher Race Conditions: Fixed stale data in the Data Viewer and broken thumbnails in the Visuals tab's Plots subtab caused by write latencies.
- Copy Plot: Fixed copy-to-clipboard on Windows and macOS using native CLI utilities.
- Test Script: Resolved line length lint errors in `.tmp/test.R`, replaced `library()` imports with `::`, and adjusted Plotly title spacing.
- Pre-Release Hardening: Safely quote R commands generated from file paths, custom plot directories, package names, and variable names.
- Viewer Server Security: Hardened the local Viewer file server against path traversal.
- Watcher Lifecycle: Dispose Viewer and Data Viewer filesystem watchers on layout deactivation so they cannot retain stale workspace roots.
- Documentation Hygiene: Corrected `.R-lab` naming and removed raw non-ASCII characters from source files.

## [0.3.6] - 2026-05-30

### Fixed

- Windows Blank Terminal: Fixed an intermittent race condition where the Shell Terminal and R Console would occasionally fail to spawn (showing a blank tab) on Windows by reverting to a more robust, two-step ConPTY initialization process.

### Changed

- Problems Subtab: Improved aesthetics by adding spacing to the left edge to prevent content crowding, and removed the horizontal row borders for a cleaner, less cluttered layout.
- Problems Subtab: Fixed an issue where the icon colors did not match the user's active VS Code theme due to Content Security Policy restrictions.

## [0.3.5] - 2026-05-30

### Fixed

- Mac/Linux Terminal Crash: Fixed a bug where toggling the layout off without an active workspace would cause the integrated terminal to crash (displaying a warning icon) on macOS and Linux by conditionally re-enabling strict environment isolation for Unix platforms.

## [0.3.4] - 2026-05-30

### Fixed

- Windows Blank Terminal: Fixed a bug where the standard Shell Terminal would fail to spawn (showing a blank tab) in no-workspace scenarios on Windows due to improperly strict environment variable enforcement.
- Windows R Path Resolution: Fixed a critical bug where unquoted Windows paths with spaces were truncated by the regex arguments parser, which caused the R Console to fail to spawn and the Data/Help viewers to throw "Rscript ENOENT" errors.

## [0.3.3] - 2026-05-30

### Added

- Workspace Subtabs: Replaced the single global environment list with a robust three-tab system: Global Environment, Packages, and Attached Objects.
- Interactive Package Management: You can now search, filter (All, Attached, Loaded), and instantly attach/detach R packages directly from the new Packages tab.

### Fixed

- R Environment Leakage Prevention: Wrapped internal snapshot and plot device scripts in `local({...})` to completely prevent internal `.vars` and `null_dev` objects from bleeding into the user's R Global Environment.
- Packages Column Layout: Ensured the checkbox column has a sticky positioning with fixed width, and prevented package titles from text-wrapping for smoother horizontal scrolling.
- Hover Bleed-Through: Fixed a CSS bug where hovering over a sticky column allowed text underneath to bleed through by layering background gradients.

## [0.3.2] - 2026-05-27

### Added

- Smart Execution Button Behavior: The "Source File to R Console" button now dynamically changes to "Run Selection in R Console" when text is highlighted in the editor.
- Context Menu Integration: Added a high-priority "Run Selection in R Console" command to the editor context menu.
- R Markdown & Quarto Support: Native code execution routing (Run Smart / Run Selection) now seamlessly supports `.Rmd` and `.qmd` files, with built-in protection against accidentally sourcing markdown files.

### Changed

- UI Standardization & Scaling: Migrated all Webview panels from static pixel sizes to responsive scaling. Standardized empty-state SVGs to a consistent 5em size with 30% opacity.

### Fixed

- Robust Shell Path Resolution: Rewrote the internal argument parser to correctly split commands and arguments. Terminal paths with flags (e.g., `radian --no-history`) and tilde paths (`~/`) now work flawlessly out of the box.
- Windows Support: Fixed an issue where the extension was not working on Windows

## [0.3.1] - 2026-05-22

### Changed

- Marketplace Image Fix: Updated README.md showcase image to use a public HTTPS URL hosted in a separate public assets repository, fixing broken images for private extension deployments.
- Refactoring: Reorganized code structure for improved readability and maintainability.

### Fixed

- PTY Crash Prevention: Fixed a critical bug causing yellow caution triangles and terminal re-evaluation crashes in no-workspace scenarios by enforcing `strictEnv` and manually merging environment variables.

## [0.3.0] - 2026-05-15

### Added

- Integrated R Help Upgrades: Implemented KaTeX mathematical equation rendering, a Smart Linker for automatic cross-references in the "See Also" section, and a "Run" button for interactive execution of code examples directly to the R console.
- Advanced Diagnostics: Upgraded the Problems view to use official VS Code Codicons, added accordion-style collapsible file groupings, and introduced per-file problem count badges.
- Seamless Top Pane Maximization: Implemented a CSS-based content-hiding strategy that minimizes the bottom-right panels to show only their tab bars, maximizing usable workspace without breaking VS Code's editor group constraints.
- Robust Layout Restoration: Engineered a two-step restoration logic (pixel equalization + proportional re-stamping) that prevents horizontal layout corruption on short windows while ensuring panes resize proportionally during window expansion.
- Progress-Synced Notifications: Replaced static informational messages with ephemeral progress-bar notifications that stay in sync with actual activation/deactivation timing.
- RStudio 3-Pane Editor Layout: Reorganized the layout so the Source editor occupies the full left side, with two panes on the right.
- Plot Redirection: Added Set View Dir and Set View/Out Dir to the Visuals tab's Plots subtab for real-time redirection of R plot output.
- Smart Plot Appending: Implemented directory scanning to automatically increment plot IDs and prevent overwriting.
- Run Source Icon: Added a theme-responsive Source File icon to the editor title bar.

### Changed

- Aesthetic Refinement: Polished the Workspace Explorer and Data Viewer table headers with refined typography (`font-weight: 600`, `font-style: italic`) for a more consistent, native VS Code look.
- Local Workspace Structure: Introduced a private `temp/` directory (automatically ignored via `.git/info/exclude`) for local scratchpads and experimental assets.
- Documentation Overhaul: Standardized the README, internal source comments, and project manifests to reflect the latest feature set.
- Webview Architecture: Migrated all sidebar panels (Environment Explorer, Data Viewer, Plots) from Activity Bar WebviewViews to Editor Grid WebviewPanels for deep layout integration.
- Terminal Management: Implemented robust terminal reuse and vanishing console protection.
- Settings Preservation: The layout toggle now meticulously saves and restores global VS Code settings (`closeEmptyGroups`, `terminal.integrated.defaultLocation`) to avoid destructive overwrites.
- Cleanup Logic: The `.R-lab` directory is now cleaned up unconditionally on shutdown.
- UI Polish: Updated plot gallery with theme-responsive backgrounds and refined rounding.
